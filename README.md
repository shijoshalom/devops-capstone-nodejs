# DevOps Capstone - Node.js Application

A Node.js web application for an end-to-end DevOps capstone project.

## Technology Stack

- Node.js
- Git and GitHub
- Jenkins
- Docker and Docker Hub
- AWS EC2
- SonarQube
- Prometheus and Grafana
- Bash and cron

## Application Endpoints

- `/` - Application homepage
- `/health` - JSON health response

## Run Locally

```bash
npm start
